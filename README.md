# Kraviny ze Sauny – Public Social Assets

Repozitář obsahuje volně dostupné MP4 soubory a popisy pro Instagram/Facebook Reels & Stories.

## Aktuální balíčky

- `heat_shock_protocol/shorts/` – 9:16 klipy (≤60 s) připravené pro Reels.
- `heat_shock_protocol/stories/` – Story segmenty (pořadí viz `captions/instagram_story.txt`).
- `heat_shock_protocol/captions/` – Texty ke kopírování (Reel + Story pořadí).

Videa pomohou obcházet limit Instagram API: stačí stáhnout MP4 soubory přes veřejný GitHub link a vložit do `--video-url` / mobilní aplikace.

## Publikace

1. Klikni na konkrétní `.mp4`, zvol „Download“.  GitHub poskytne trvalý HTTPS odkaz použitelný pro Instagram Graph API.
2. Nebo stáhni celý adresář jako ZIP pro manuální upload z telefonu.

Repo lze průběžně doplňovat o další skladby (`champions_of_sweat`, `cooling_paradox`, …).
